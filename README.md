# issm-ssp-poam-portfolio

RMF-aligned System Security Plan and POA&M tracker demonstrating ISSO/ISSM documentation practices — portfolio exercise.

## About This Project

This repository contains a fictional System Security Plan (SSP) and Plan of Action & Milestones (POA&M) built to NIST SP 800-18 and NIST SP 800-53 Rev. 5 standards. It's a hands-on demonstration of the core documentation an ISSO or ISSM owns throughout the Risk Management Framework (RMF) lifecycle: defining a system's authorization boundary, categorizing it under FIPS 199, selecting and implementing security controls, and tracking remediation of control gaps.

**Note:** The system documented here ("CaseTrack") is entirely fictional. No real organization, agency, or data is represented.
